# 记录格式（待重写，不要照此开工：用户 2026-11-13 说架构不清晰，块内部还没定）

这一页定两样东西各记什么：一个实验，一个物件。只定内容，不定存成什么文件。

操作台显示的"实际输入"和仪表盘显示的"任务现状"，都从这两样记录里算出来。

## 1 一个实验记什么

| # | 项 | 内容 | 谁写 |
|---|---|---|---|
| 1 | 编号 | 系统给，不重复，不复用 | 系统 |
| 2 | 类型 | 重建、FEA、代理、优化，四选一。同时记这一类的插件是哪一版、插件文件的哈希 | 你选，系统记版本 |
| 3 | 说明 | 这个实验想做什么，一两句。之后随时可以加备注 | 你 |
| 4 | 标签 | 你自己打的词。系统不解释它 | 你 |
| 5 | 实际输入 | 这个实验用的每一样输入，见第 2 节 | 你填，启动时系统存定 |
| 6 | 操作 | 新建、启动、暂停、继续、停止、重试，各记时间 | 系统 |
| 7 | 任务 | 启动后实际在跑的每个任务：状态每变一次记一条，带阶段、时间、机器 | 插件报，系统记 |
| 8 | 产物 | 跑出来的东西。每样自动登记成一个物件，这里记物件编号 | 插件报，系统记 |
| 9 | 问题 | 哪个任务、什么错、原始报错。记下来，不拦别的 | 系统 |

另记一条来历：启动时的代码提交号、机器；FEA 实验加内核哈希。

## 2 实际输入里的每一样记什么

| 项 | 内容 |
|---|---|
| 名字 | 这类实验规定的输入名，见 `docs/骨架方案.md` 第 1.4 节 |
| 物件 | 物件的编号、种类、版本、哈希 |
| 来路 | 跟着物件走：系统里哪个实验的产物，或从外面登记进来的 |

- 启动前可以反复改填，每次都留在记录里。
- 启动时存定。存下的是当时实际用的那一份；启动后不能改，要改就新建一个实验。
- 启动时把每个物件的哈希再核一遍，对不上不让启动。

## 3 任务的状态

只有五种：排队、运行、完成、失败、停止。每一类自己的阶段名（建模、求解之类）另写在"阶段"里。

## 4 一个物件记什么

| 项 | 内容 |
|---|---|
| 编号 | 系统给，不重复，不复用 |
| 种类 | 一个词：骨模型、一批点、数据、预测器、策略、目标、定义、设定 |
| 名字和版本 | 你起的名字；同一个名字再登记一次，版本加一 |
| 内容 | 三种存法：一个值；原文复制一份；大文件只记位置 |
| 哈希 | 登记时算 |
| 来路 | 外面拿来的：从哪拿的、什么时候、你写的一句说明。实验的产物：哪个实验的哪一样 |
| 登记时间 | 系统记 |

- 登记后不改、不删。要改就登记一个新版本，旧版本还在。
- 一个物件被哪些实验用过，由实验的记录算出来，不另记。

## 5 只追加

- 实验的记录和物件的登记都只追加，写了不改。
- 每条带序号和上一条的哈希。改过一条或删过一条，核对能指出是哪一条。

## 6 这一页没有定的

- 存成什么文件、放在哪个文件夹。由做第 1 块的对话提，你定。
