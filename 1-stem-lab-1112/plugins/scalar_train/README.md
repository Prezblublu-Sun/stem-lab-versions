# scalar-train：用一份标签表训练标量预测器

类别：代理。只在本机 CPU 上算。一种实际操作一个插件，这个插件只做"训练标量预测器并出误差报告"这一件事。

**没做的：** 场预测器（整体应变场、界面场）。它要等整体场的数据，这个插件里没有。神经网络、图网络等别的模型种类也没有。

## 设置（六项，都必填）

| 设置 | 内容 | 例 |
|---|---|---|
| 训练数据 | 一份标签表：平的 CSV，一行一个 FE 作业。用"只记位置"填，记录里只有位置和哈希 | `db3406/v0.14/scalars.csv` |
| 数据怎么读 | 用哪些行；骨、设计、条件各是哪几列 | 见下 |
| 预测目标 | 预测哪几列。每列可以写变换 `log10`，不写就不变换 | `[{"列": "rot_first_deg", "变换": "log10"}, "contact_area_load2_mm2"]` |
| 模型和训练配置 | 模型种类和它的配置；算哪几个误差指标 | 见下 |
| 划分 | 训练和留出怎么分 | 见下 |
| 随机种子 | 不小于 0 的整数 | `0` |

每一项可以直接填 JSON 的值，也可以给一个内容是 JSON 的文件。写错的键会被点名，不会被悄悄忽略。

**数据怎么读**

```json
{"行的名字": "row_id",
 "行的筛选": {"status": "DONE", "kind": "design", "has_fric_model": "true"},
 "最多用几行": null,
 "骨": "femur_id",
 "设计": ["L", "alpha", "h_cut", "m", "rho_tip", "q", "lam", "g_ml", "g_ap", "n_a", "n_p", "tau_a", "tau_p"],
 "条件": ["delta_mm"]}
```

- `行的筛选`：列等于某个值（或几个值之一）的行才用。
- `最多用几行`：筛选之后按表里的顺序取前几行。不写就全用。
- 输入或目标缺值的行去掉，哪些行、缺什么都写进误差报告。

**模型和训练配置**

| 模型种类 | 配置（括号里是默认） | 不确定度 |
|---|---|---|
| `高斯过程` | `核`（`Matern52`；还有 `Matern32`、`RBF`）、`重启次数`（3）、`长度尺度范围`（[0.2, 200]）、`噪声范围`（[2.5e-4, 0.1]） | 模型自带的方差 |
| `随机森林` | `树的棵数`（300）、`叶子最少行数`（1）、`每次分裂看的输入比例`（1.0） | 集成：各棵树的预测之间的离散 |

两种都可以加 `"误差指标": ["R2", "RMSE", "MAE", "相对误差", "秩相关"]`，不写就全算。90% 区间覆盖率总是给。
输入的归一化是固定的：每一列减训练行的均值、除以训练行的标准差。每个目标各训练一个模型。只用一个线程。

**划分**

| 种类 | 写法 | 报的数叫什么 | 存下的预测器用哪些行训练 |
|---|---|---|---|
| 留出 | `{"种类": "留出", "留出比例": 0.2, "分组列": "design_key"}` | 留出误差 | 训练行。留出行不进训练 |
| 按列 | `{"种类": "按列", "列": "split", "留出的值": ["test"]}` | 留出误差 | 训练行。留出行不进训练 |
| k 折 | `{"种类": "k 折", "折数": 5, "分组列": "design_key"}` | 交叉验证误差 | 全部行。每一折的模型不见自己那一折；存下的预测器是之后用全部行另训的，所以这个数不是它的留出误差 |

`分组列` 可以不写。写了就整组一起走：同一组（比如同一个设计）的行不会一边在训练、一边在留出。

## 任务

一个任务，叫"训练"。启动后在后台进程里算，马上返回。阶段：读数据、划分、训练并算误差、（k 折时）用全部行训练要存的预测器、算误差、写产出。

- 停止：把后台进程停掉。
- 重试：设置不变，重新算一次，写进新的文件夹（`outputs/2/`）。上一次的留着。
- 暂停：只是操作台不来看，后台进程照常算。

## 产出

| 产出 | 文件 | 内容 |
|---|---|---|
| 预测器 | `outputs/<第几次>/预测器.zip` | 格式"标量预测器 v0"。里面三个文件：`manifest.json`（输入、目标、训练用的数据哈希和行、配置、包的版本）、`model.joblib`（每个目标一个 scikit-learn 模型）、`hashes.json`（前两个的哈希） |
| 误差报告 | `outputs/<第几次>/误差报告.json` | 误差叫什么；预测器是用哪些行训练的；数据的位置和哈希；用了哪些行、去掉了哪些行；划分的每一折的训练行和留出行；指标的定义；每个目标的误差；留出行上逐行的真值、预测、标准差 |

误差报告里没有时间，也没有实验编号。同设置同种子重跑，这个文件的每个字节相同。

## 旧代理仓库的五个毛病，这里怎么对

| 旧仓库 | 这里 |
|---|---|
| 没有配置文件格式，每轮一个手写的任务脚本 | 六项设置进实验记录，启动时存定 |
| 记录里的代码版本不可靠 | 实验记录里有插件文件夹的哈希（地基记的）和 `worker.py` 的哈希 |
| 不记数据哈希和训练行 | 误差报告、预测器、实验记录三处都有数据哈希；训练行逐行列出并有哈希 |
| 五折划分里留出的行也进了训练 | 留出时预测器只见训练行，有测试守着；k 折的数明说是交叉验证误差 |
| 输出目录已存在时不拒绝 | 产出文件夹已经在了就不写，报错 |
