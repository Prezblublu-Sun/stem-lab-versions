# Lane：照着跑一份选点策略

Lane 是一个插件，类别报的是"优化"。它吃一份你在系统外调好的策略、目标和约束、候选池，在本机另开一个 Python 进程跑一次，产出一批点。

它只负责照着跑并记全。它不评价策略，不解释目标、约束和候选池的内容，不碰有限元，不碰旧系统和 Linux。
怎么比较策略、怎么调参数都在系统外做；调好了，改的是这里的设置，不用动 Lane。

## 1 设置

| 设置 | 必填 | 内容 | Lane 怎么用 |
|---|---|---|---|
| 策略 | 是 | 一个 Python 文件，或一个带 `strategy.py` 的文件夹 | 复制一份到这次运行的文件夹里，跑的是复制件。用"复制文件"填，原文就存在实验里 |
| 目标和约束 | 是 | 一个值，或一个文件 | 原样交给策略 |
| 候选池 | 是 | 一个值，或一个文件 | 原样交给策略 |
| 预测器 | 否 | 一般是另一个实验的产出 | 原样交给策略 |
| 已有数据 | 否 | 起点用哪些已有的点 | 原样交给策略 |
| 选几个点 | 是 | 正整数 | 交给策略；策略给多了算不合约定 |
| 随机种子 | 是 | 0 到 4294967295 的整数 | 交给策略；跑之前用它固定全局随机数 |

每一项都可以来自别的实验的产出，也可以来自其他来源。Lane 不规定先后。

算法的配置（配比、采集函数、阈值等）写在策略文件里，或放在策略文件夹里。换配置就是换一份策略，新建一个实验。

## 2 策略的约定

策略文件里要有一个函数：

```python
def select(inputs):
    ...
    return [点, 点, ...]
```

**吃什么。** `inputs` 是一个字典，键就是上面的设置名（"策略"除外）：

| 键 | 值 |
|---|---|
| `目标和约束`、`候选池` | 设置填的是值，就是那个值；填的是文件，就是一个 `pathlib.Path` |
| `预测器`、`已有数据` | 同上；没填是 `None` |
| `选几个点`、`随机种子` | 整数 |

文件是什么格式、怎么读，由策略自己定。

**返回什么。** 一个列表，一个点一项，每项是一个字典：

| 键 | 必须 | 内容 |
|---|---|---|
| `设计` | 是 | 这个点的设计。放什么由策略定（比如 13 个单位坐标） |
| `理由` | 是 | 一段文字：为什么选它 |
| `名字` | 否 | 一段文字，一批里不能重。不给的话 Lane 按顺序叫 `p01`、`p02`… |
| `条件` | 否 | 这个点的条件（载荷、摩擦系数等）。不给就是空的 |
| 别的键 | 否 | 分数、组别、预测值等。原样留在产出里。点属于哪根骨也这样给，键叫 `骨` |

里面只能是能存成 JSON 的东西。numpy 的数和数组会转成普通的数和列表；非数（NaN）和无穷不行。

**几条规矩。**

- 点的个数不能超过"选几个点"。超过了算不合约定，Lane 不替策略决定去掉哪几个。
- 少于"选几个点"可以：给出的点照常产出，另记一条问题。
- 一个都没有，算失败。
- 策略可以 `import` 自己文件夹里的别的文件，和这台机器上装着的包。
- 策略运行时的当前文件夹是这次运行的 `work` 文件夹，往相对路径写的东西落在那里。
- Lane 不检查选出的点在不在候选池里、满不满足约束。那是策略的事。

示例见 `examples/随机取可行点.py`，配套的 `examples/候选池.json` 和 `examples/目标和约束.json`。示例只用来演示约定，不是一份真的选点策略。

## 3 任务和产出

一个实验一个任务，名字叫"选点"：排队 → 运行 → 完成或失败。

产出一项，叫"一批点"，文件是 `outputs/一批点.json`。最外层是一个列表：

```json
[
 {
  "名字": "c16",
  "设计": {"x1": 0.6, "x2": 0.25},
  "条件": {},
  "理由": "在 13 个可行候选里随机抽中（种子 7）；去骨量 5.9 不超过 6.0"
 }
]
```

每个点前四个键固定是名字、设计、条件、理由，后面是策略另给的键。
这个文件里只有点，没有时间和实验编号，所以两次运行可以直接比文件哈希。

## 4 同设置同种子，重跑得到同一批点

Lane 做了四件事：

| 做法 | 管住什么 |
|---|---|
| 每次都另开一个新的 Python 进程 | 上一次运行留下的状态 |
| 把种子交给策略：`inputs["随机种子"]` | 策略自己建的随机数发生器 |
| 调 `select` 之前，用种子固定 `random`；策略装了 numpy、torch 的话也一并固定 | 策略没有自己设种子的全局随机数 |
| 进程的 `PYTHONHASHSEED` 设成 0 | 集合和字典键的顺序 |

Lane 管不住的：策略自己去取系统的随机源或时间；多线程和 GPU 上的不确定；换了包的版本；换了机器。
包和版本每次都记在实验的来历里（"策略跑完"一项），可以对照。

## 5 出问题时

出问题是正常的。下面每一种都记成这个实验的一条问题，任务报失败，实验结束，不影响别的实验：

| 情况 | 记下的原始报错 |
|---|---|
| 策略出错（包括语法错、自己退出） | 完整的出错位置，加策略的标准错误输出的末尾 |
| 策略文件里没有 `select` | 同上 |
| 策略的进程没留下结果就没了 | 策略的标准错误输出的末尾 |
| 返回的东西不合约定 | 哪里不合，加返回内容的开头 |
| "选几个点"或"随机种子"填得不对；策略填成了一个值 | 哪一项、填的是什么 |

原始报错在实验记录里有一份，在 `plugin_state/run_NN/原始报错.txt` 里另有一份。

设置在启动时就存定了。所以设置填错只能新建一个实验重填；重试只对环境上的问题有用（比如缺一个包，装好了再重试）。

## 6 停止、暂停、重试

| 操作 | Lane 做什么 |
|---|---|
| 停止 | 在运行文件夹里放一个 `stop` 文件，策略的进程看到就自己退出（一般不到一秒）。任务报停止 |
| 暂停 | 什么都不做。策略的进程照常跑；暂停期间操作台不来看，继续之后再收结果 |
| 重试 | 任务是失败或停止的：设置不变，重新跑一次，用新的运行文件夹。任务已经完成的：没有要重做的，实验回到已结束 |

Lane 没有设最长运行时间。策略跑得久就一直是运行中，要停就点停止。

## 7 每次运行留下什么

在实验文件夹的 `plugin_state/run_NN/` 里（NN 是第几次运行）：

| 文件 | 内容 |
|---|---|
| `策略/` | 这次实际跑的那份策略 |
| `job.json` | 交给策略的 `inputs`，和策略的哈希 |
| `stdout.txt`、`stderr.txt` | 策略打印的东西 |
| `done.json` | 策略返回的原样，或出错信息；用时；装进来的包和版本 |
| `原始报错.txt` | 出问题时才有 |
| `work/` | 策略运行时的当前文件夹 |
| `pid.txt` | 策略进程的进程号 |

## 8 文件

| 文件 | 是什么 |
|---|---|
| `plugin.py` | 插件：报四样；启动、报任务状态、停止、重试 |
| `runner.py` | 运行器：在单独的进程里固定种子、叫 `select`、写结果。不认识实验记录 |
| `examples/` | 示例策略、示例候选池、示例目标和约束 |
| `tests/test_lane.py` | 测试，用临时文件夹当 home |

测试在仓库根上跑：

```bash
PYTHONUTF8=1 python -m pytest plugins/Lane/tests -q -p no:cacheprovider
```

## 9 在操作台里走一遍

```bash
PYTHONUTF8=1 python -m stemlab new Lane --note "示例策略走一遍"
```

```bash
PYTHONUTF8=1 python -m stemlab set E0001 策略 --file plugins/Lane/examples/随机取可行点.py --source "Lane 自带的示例"
```

```bash
PYTHONUTF8=1 python -m stemlab set E0001 目标和约束 --file plugins/Lane/examples/目标和约束.json --source "Lane 自带的示例"
```

```bash
PYTHONUTF8=1 python -m stemlab set E0001 候选池 --file plugins/Lane/examples/候选池.json --source "Lane 自带的示例"
```

```bash
PYTHONUTF8=1 python -m stemlab set E0001 选几个点 --value 5 --source "手填"
```

```bash
PYTHONUTF8=1 python -m stemlab set E0001 随机种子 --value 7 --source "手填"
```

```bash
PYTHONUTF8=1 python -m stemlab start E0001
```

```bash
PYTHONUTF8=1 python -m stemlab refresh E0001
```

```bash
PYTHONUTF8=1 python -m stemlab show E0001
```

把这批点交给另一个实验：

```bash
PYTHONUTF8=1 python -m stemlab set E0002 点 --from-exp E0001 --output 一批点
```
