## 一、要满足的

1. **三种来源，写出来是同一种骨模型**：
   - CT 重建：CT 加一份股骨的外形；
   - CAD：STEP 实体；
   - STL：封闭的 STL 实体，加上皮质、松质的材料设定。
2. **以后能按骨密度连续地给材料**：格式现在就留出位置，以后不用改格式。
3. **不预设原项目的做法**：几个区域、各叫什么、材料怎么给，由骨模型自己声明。
4. **用骨模型的一方自己说要什么**：柄空间包、有限元包、推导量定义各自声明，启动前照声明核对。
5. **身份和内容**：一根骨的所有版本共用一个骨标识，每个版本的内容按哈希定住。这一点照旧。
6. **几块骨组成的关节**（补）：比如髋骨、股骨，加上两层软骨。每块有自己的坐标系；块和块之间的相对姿态由每个点给，比如走路、上楼时的关节角。
7. **不只是封闭的实体**（补）：
   - 壳：一张面加厚度，比如薄的皮质；
   - 二维或平面模型，加厚度；
   - 现成的体网格：别处划好的网格直接收。
8. **不只是线弹性**（补）：超弹性，比如软骨的 neo-Hookean；以后可能还有别的。
9. **按密度给材料的位置写成分段的表**（补）：文献里常用的 Keyak 式公式就是分三段的。

## 二、一份骨模型里有什么

一个文件夹，里面是一份清单加若干文件。清单分十段：

| 段 | 写什么 |
| --- | --- |
| 1 身份 | 主体标识（现在叫骨标识，从骨源继承；几块骨的关节怎么标，见第八节）；左右；骨的种类（真骨、模型骨、合成的）；覆盖范围：完整股骨，还是近端一段，各多长；维度：三维、平面应变、平面应力（带厚度）、轴对称（补）；说明 |
| 2 来源 | 骨源的编号；怎么来的：CT 重建、CAD 导入、STL 导入、体网格导入；重建方法包的编号和版本；用的设定的编号；哪个实验的哪一轮 |
| 3 单位和坐标 | 单位从系统的单位表里选，比如长度 mm、力 N、应力 MPa、密度 g/cm³、质量 kg。导入时换算，换算记进重建记录。坐标系：几何文件自己的坐标，加上到骨的解剖坐标系的变换（原点和三个轴）。约定写明，比如右股骨 x 指向内侧、y 指向后方、z 指向近端，左股骨怎么镜像。几块骨时，每块各有一个坐标系 |
| 4 块（补，几块骨时才有） | 每一块写：名字、角色（股骨、髋骨等）、自己的坐标系。关节写：哪两块、绕哪个中心、有哪几个自由度。相对姿态不写死在骨模型里，由每个点给：有限元设定里声明，用名字引用关节 |
| 5 区域 | 一个或多个区域，几块骨时写明属于哪一块。每个区域写：名字、角色、几何的种类和文件、体积、和别的区域的关系（谁包着谁，哪些面是两区共用的界面） |
| 6 材料 | 每个区域一种给法，见第三节 |
| 7 表面 | 用得到的命名表面：外表面（骨膜面）、内壁（骨内膜面）、髓腔面、可以截骨的范围、关节面等。可以由区域导出，也可以单独给 |
| 8 标志点和轴 | 每个点或轴写：值（在骨的坐标系里）、属于哪一块、定义（找法的名字、版本、参数）、拟合的好坏。常用的有股骨头中心和半径、颈轴、颈部最细的截面、干轴、小转子、后髁、长度。定义里写这根骨实际用的区段和数，不写死尺寸 |
| 9 检查结果 | 检查门的每一条：线、值、过没过；网格试划的结果；量出来的数，比如体积、壁厚 |
| 10 重建记录 | 每一步做了什么；人工修改：谁改的、为什么、改了哪里；用的设定 |

**几何的种类**（补）：

| 种类 | 说明 |
| --- | --- |
| 封闭的实体 | STEP 或 STL |
| 壳 | 一张面加厚度；厚度是一个数，或者按位置给 |
| 二维区域 | 平面模型用，厚度写在身份里 |
| 现成的体网格 | 单元和节点都给了，有限元包不再划网格 |

**区域的角色**：先定这几种（第八节要你定）：
- 皮质；
- 松质；
- 髓腔（空的）；
- 软骨（补）；
- 其他。

**例子**：原项目 3406 那根模型骨，泡沫芯以下的髓腔是空的。在这种写法里，那一段就是一个角色为“髓腔（空的）”的区域，而不是写在求解代码里的一条规则。

## 三、材料的给法

每种材料模型的参数都照 Abaqus 的写法给。有限元包声明自己支持哪些材料模型，不支持的，启动前就拒。

**均匀的线弹性**：

| Abaqus | 写什么 |
| --- | --- |
| `*ELASTIC`，各向同性 | 弹性模量 E、泊松比 ν |
| `*ELASTIC, TYPE=ENGINEERING CONSTANTS` | 正交各向异性的九个常数，和材料主方向（相对骨的坐标系） |
| `*DENSITY` | 密度，可选 |

**超弹性**（补）：

| Abaqus | 写什么 |
| --- | --- |
| `*HYPERELASTIC, NEO HOOKE` | C10、D1；也可以写成剪切模量 G 和体积模量 K，导入时换算 |
| `*HYPERELASTIC, MOONEY-RIVLIN` | C10、C01、D1 |

每个数都写来路：厂家资料（比如 Sawbones 第四代 PCF 20 泡沫，155 MPa）、文献、或者测量。

**按骨密度连续变化的**（以后做，现在只留位置；补成分段的表）：

| 写什么 | 说明 |
| --- | --- |
| CT | 用哪一份 CT（登记的编号），通常就是重建用的那一份 |
| HU 到密度的标定 | 直线的两个系数，和用的标定体模 |
| 密度到模量的关系 | 一张分段的表：每一段写密度的范围、公式 E = a·ρ^b 的两个系数、来路。文献里常用的 Keyak 式就是三段 |
| 泊松比 | 一个数 |
| 上下限 | 模量的最小值和最大值 |
| 分档 | 分成多少档。Abaqus 里常用的做法是按档分成多种材料 |
| 映射方法 | 比如按单元取平均 |

骨模型只写“怎么给”，把材料映射到单元上是有限元包的事。

## 四、几种来源各怎么写

| 来源 | 区域 | 材料 | 标志点 |
| --- | --- | --- | --- |
| CT 重建 | 重建方法包分出皮质和松质（内部）两个区域，以后可以更多。几何是 STL | 均匀的照设定给；以后也可以用同一份 CT 按密度给 | 自动找，人看过 |
| CAD | 你把每个 STEP 文件对到一个区域和角色上 | 照设定给，比如厂家资料 | 自动找，或者手给 |
| STL | 同 CAD，文件是封闭的 STL | 照设定给 | 同上 |
| 现成的体网格（补） | 你把网格里的单元集对到区域和角色上 | 照设定给 | 同上 |
| 几块骨（补） | 每块各从自己的骨源来（上面几种都行），再写块和关节 | 各区域照设定给 | 每块各自找 |

几种都由重建这种实验产出（出候选、人看、定稿），用不同的重建方法包，写出来是同一种格式。

## 五、用骨模型的一方怎么说要什么

| 谁用 | 声明要什么 |
| --- | --- |
| 柄空间包 | 要哪些标志点，照哪种定义；要哪些表面（比如内壁）、哪些角色的区域；覆盖范围至少要多长，比如到小转子下多少 |
| 有限元包 | 支持哪些几何种类（实体、壳、二维、体网格）、哪些维度、哪些格式（STEP、STL）、哪些材料模型和给法、要不要关节（补）；或者声明不要骨模型（补，只有柄、单胞这类分析，见《核心、插件和包》第十一节） |
| 推导量定义 | 要哪些标志点和轴、哪些表面 |

启动前照声明核对；不合就拒，说清缺的是哪一样。用的一方不认骨标识，只认骨模型声明了什么。

## 六、契约里固定的核对

- 每个区域：名字唯一，角色在角色表里，几何文件在文件夹里。实体是封闭的；壳的厚度为正；二维模型写了厚度；体网格没有翻转的单元（补）。
- 区域之间的关系自洽：包含关系不成环，共用的界面两边都在。
- 几块骨时（补）：每个区域都属于一块；关节两端的块都在；关节的中心和轴在块的坐标系里写清。
- 每个区域有且只有一种材料给法，给法要求的项都在，数值在合理的范围里。比如模量为正、泊松比在 0 到 0.5 之间、超弹性的参数为正、分段的表各段不重叠。
- 单位都在单位表里。坐标变换的三个轴互相垂直、长度为一。
- 每个标志点都写了定义。
- 骨标识从骨源继承。登记一个没见过的骨标识，要明说是新骨。这一条照旧。

## 七、和现在的差别

- **现在**：
  - 恰好两个实体（`cortical`、`cancellous`），每个一种均匀的线弹性材料，单位只有一套。
  - CAD 只认两个 STEP。
  - STL 只出现在 CT 那条路的中间，不能直接当骨源。
  - 标志点的定义写死了尺寸。
  - 只能是一根骨、三维、封闭的实体；不收体网格；没有超弹性（补）。
- **改成**：
  - 区域可多可少，都有角色；几何有四种（补）；
  - 可以是几块骨组成的关节（补）；
  - 材料有线弹性、超弹性和按密度三种给法（补）；
  - 单位和坐标变换写明；
  - 几种来源写出来同一种格式；
  - 用的一方各自声明要什么。
- **已有的骨模型**：格式升一版。旧版本照“一块骨、两个区域（皮质和松质）、均匀材料”读进来，不用重做。

## 八、要你定的

1. 区域的角色先定哪几种：皮质、松质、髓腔（空的）、软骨、其他。还要不要别的？
2. 按骨密度给材料：现在只在格式里留位置（已经补成分段的表），还是第一版就做？蓝图写的是 1.0 不做。
3. 坐标：我建议统一用一种解剖坐标系，每根骨记下从文件坐标到它的变换。
4. 覆盖范围（完整股骨，还是截断的近端一段）要不要写成必填。我建议必填，因为柄的放置和远端固定都要用它。
5. 几块骨的关节（补）：现在做，还是先留位置？要做的话，每块骨分开重建再拼起来，会碰到蓝图“1.0 不做的”批量重建。
6. 主体标识（补）：几块骨的关节、只有柄、单胞这几种情形，“主体”是什么，标识怎么叫？骨标识是改叫“主体标识”，还是另加一种？这和《核心、插件和包》第十一节“没有骨的分析”是同一件事。
7. 材料模型第一版收哪几种（补）：线弹性（各向同性、工程常数）、超弹性（neo-Hookean、Mooney–Rivlin）收进来，按密度的先留位置。这样行不行？
