## 〇、已经定了的（2026-11-15，你定的）

1. **设计空间放在包里**：FEA 只有一套流程。
2. **叫法**：管柄的形状和放置策略的包，叫“柄空间”。
3. **有限元的做法照 Abaqus 的设定**。
4. **默认值随包放入**，用来跑测试轮。
5. **骨模型**可以来自 CT 重建，也可以直接用 CAD 或 STL 文件，加上皮质、松质的材料设定；以后可能按骨密度连续地给材料。
6. **别的三种实验**（重建、代理、优化）也照这个思路复核，重新设计。
7. **原来的“内核”拆成两个包**（我提的，你认了）：
   - **柄空间包**：柄的形状和放置。
   - **有限元包**：照 Abaqus 的设定建模、求解、后处理。

   建模、求解、后处理也是会换的做法，要有自己的版本和身份，数据才说得清是怎么算出来的。

## 一、五层，各管什么

| 层 | 管什么 | 多久变一次 | 怎么进来 |
| --- | --- | --- | --- |
| 核心 | 记账；实验的生命周期：新建、填、启动、轮询、停止；发布产物、记来历；照声明核验设定（只此一份） | 几乎不变 | 冻结 |
| 每种实验的插件 | 冻结的部分：这种实验的流程骨架、输入表和产物表、结局怎么归类、评判规则。自由的部分：怎么跑，比如排队、起进程。插件只声明自己的运行设定 | 很少，加一种新的分析才变 | 冻结的骨架，加自由的执行代码 |
| 包 | 会换的做法：柄空间、有限元、推导量定义、重建方法、代理模型、选点策略，以及训练出来的预测器 | 有时变 | 发布新版本，按哈希定住 |
| 设定 | 一次研究的取值，照包或插件的声明核验 | 经常变 | 登记一份新的设定，写全 |
| 来源 | 骨源和骨模型、一批点、数据、旧库；实测数据和登记过的对照（补） | 每根骨、每批点 | 登记 |

“核心管流程”指的是前两层：核心管所有实验都一样的那部分，插件里冻结的骨架管这一种实验的那部分。两层都冻结。

## 二、每个包都有的五样

1. **身份**：名字、版本、代码的哈希；用到的外部程序及其版本，比如 Abaqus 2025。
2. **声明的设定**：每一项写名字、单位、含义、类型（数、整数、几选一）、允许的范围或可选的值、必不必填。核心照它核验，页面照它画表单。
3. **对输入的要求**：比如要骨模型的哪些标志点、哪些区域。启动前照它核对。
4. **产出**：每一列、每个场的名字、单位、含义。
5. **测试轮的默认设定**：一整套写全的设定，加上自检的样本。只用来跑测试轮，正式的轮不靠隐含的默认值。

包的种类：

| 包 | 哪种实验用 | 管什么 |
| --- | --- | --- |
| 柄空间包 | FEA、优化 | 柄的模型和放置（补，原来只写了形状和放置）：柄怎么参数化（设计项，或目录里的型号）；柄的模型：区域、各区的材料（均匀、分段、按场）、命名的面组、特征点和轴；放置策略：截骨、放柄、入口、对线；放不放得下、去多少骨（模板化）。可以不用，明说无植入物 |
| 有限元包 | FEA | 照 Abaqus 的设定建模、求解、后处理；声明它支持哪些 Abaqus 设定，每个点上哪些可以变 |
| 推导量定义包 | FEA | 从 FE 的结果和骨模型的标志点算推导量 |
| 重建方法包 | 重建 | CT 流程、CAD 导入、STL 导入 |
| 代理模型包 | 代理 | 一种模型族怎么训练：二次岭回归、高斯过程、神经网络、POD 的场，等等 |
| 选点策略包 | 优化 | 怎么从候选里选点 |
| 预测器 | 代理、优化 | 代理训练出来的产物，本身也是包 |

## 三、测试轮

- 每种实验都能用包里的默认设定跑一轮测试：在一份参照输入上（比如造的假骨），把整条流程走通。
- 测试轮的结果标成测试，和正式的分开：不进正式的数据，不能拿来训练，也不能拿来选点。
- 正式的轮用登记的设定，写全。可以从默认值抄起来再改，但抄出来的那一份是登记过的，看得见。

## 四、FEA

**流程**（插件里冻结的骨架）。每个点：
1. 柄空间包模板化：放不放得下，去多少骨；无植入物时跳过这一步（补）；
2. 有限元包建模；
3. 求解（排求解槽）；
4. 后处理；
5. 推导量；
6. 交数据；
7. 判判据；
8. 归档。

**输入表**：

| 输入 | 说明 |
| --- | --- |
| 骨模型 | 写法见另一份。没有骨的分析（只有柄、单胞）要不要也走 FEA，见第十一节（补） |
| 一批点 | 每个点 = 设计项（柄空间声明的）+ 有限元设定、放置设定、推导量设定里写了“每个点给”的项（补，原来只有有限元的） |
| 柄空间包 | 可以不填：不填就是明说无植入物（补） |
| 放置设定 | 放置策略的参数，照柄空间包的声明；可以有每个点能变的项，比如截骨面降多少（补） |
| 有限元包 | |
| 有限元设定 | 照 Abaqus 分组，照有限元包的声明 |
| 推导量定义包 | |
| 推导量设定（补） | 照推导量定义包的声明：分哪几个区、阈值多少、取中位数还是均值；取值的位置用名字引用；可以有每个点能变的项 |
| 运行设定 | 插件声明的：求解槽、超时、归档位置 |
| 判据 | 可选，看到结果之前写定 |

**有限元设定照 Abaqus 的结构分组**：

| 组 | 对应 Abaqus 的 | 例子 |
| --- | --- | --- |
| 部件和装配 | Part、Assembly | 骨的块和区域来自骨模型，柄的模型（区域、材料、面组、特征点）和位置来自柄空间。这一组不在设定里；接触、加载都用名字引用骨和柄上的面和点（补） |
| 材料和截面 | `*MATERIAL`、`*ELASTIC`、`*HYPERELASTIC`、`*DENSITY`、`*SOLID SECTION`、`*SHELL SECTION` | 柄和骨的材料默认来自柄的模型和骨模型，均匀、分段、按场都行；按场的可以是一份预测的场（补）。研究里可以覆盖某个区域，或者列为每个点的条件 |
| 网格 | 单元类型（C3D10、C3D10M、C3D4……）、网格尺寸、界面加密 | |
| 相互作用 | 接触对；法向（硬接触、罚函数）；切向（无摩擦、罚摩擦的系数和弹性滑移、拉格朗日）；过盈（`*CONTACT INTERFERENCE`）；绑定（`*TIE`） | |
| 约束 | 加载用的耦合（`*COUPLING`）；绑定 | |
| 分析步 | `*STEP`、`*STATIC`、NLGEOM、增量的控制；步的序列：消过盈、加载、卸载、再加载、循环 | |
| 边界条件 | `*BOUNDARY`：远端固定在哪、怎么固定 | |
| 载荷 | 关节力的大小和冠状面、矢状面的角度；肌肉力（可选）；作用的方式 | 常作为每个点的条件 |
| 初始条件 | 过盈量、预应力 | |
| 输出 | 场输出和历程输出要哪些量 | |
| 作业和求解控制 | 线程数、内存、求解器、Abaqus 的版本 | |

哪些是几个可选的方案、哪些是数值，照 Abaqus 本身来：Abaqus 给的是关键字和参数选项的，就是选项；Abaqus 要填数的，就是数值。有限元包声明它支持其中哪些。

**数据是怎么算的**（`made_by`，补）：影响算出来的数的每一样输入，要么在点的哈希里，要么在 `made_by` 里。`made_by` 包括：
- 柄空间包和放置设定（所有点都一样的那部分）；
- 有限元包和有限元设定（同上）；
- 推导量定义包和推导量设定（同上）；
- 骨模型的那一版；
- 用到的预测。

不全相同的数据不混在一起用，除非登记过一份对照。详见《设定的声明和包的清单》第五节。

**判据**（补）：现在的判据只是对一批点里的一列取统计量，再和线比。四篇里有组间、成对的比较和检验，比如有领柄和无领柄比。这些放不放进系统，见第十一节。

**原项目的 M1-3406-v1**：整个当作一个参照包留着，只用来和旧库对照。

## 五、重建

**流程**（冻结的骨架）：
1. 出候选：骨源变成候选骨模型，加一份待检查清单；
2. 人看，做人工修改；
3. 定稿：用上修改、核对、过检查门，得到骨模型。

**包**：重建方法包。
- CT 流程：照你的第二版流程。
- CAD 导入。
- STL 导入。

各自声明设定（带测试轮的默认值）和能收的骨源。

**设定**：
- 重建设定，照方法包的声明；
- 每个区域的材料：均匀的，或按骨密度的；
- 标志点的找法和参数；
- 检查门的线，看到结果之前写定。

**来源**：骨源，包括 CT 和外形、STEP 文件、STL 文件。

**冻结的评判**：
- 检查门怎么判：过、不过、不可判；
- 定稿只沿用重做不了的数（今天修过的那一处）。

**和现在的差别**：
- CT 流程和 CAD 导入现在是插件里的自由代码，设定是一段 JSON；
- STL 实体不能直接当骨源；
- 骨模型的写法照另一份改。

## 六、代理

**流程**（冻结的骨架）：
- 训练：数据，按冻结的规则划分，交给代理模型包训练，得到预测器，再出误差报告。误差的算法和完整性的核对都冻结。
- 出预测。
- 复核。

**包**：
- 代理模型包：一种模型族怎么训练。声明超参数和默认值，能学标量还是场，要不要 GPU。
- 预测器：训练出来的产物。

**设定**：
- 训练设定：要预测的量（数据里声明过的列）；特征（柄空间的设计项和条件，也可以是建模时就有的场，比如积分点的坐标，补）；超参数，照模型包的声明。
- 划分。
- 合格线：看到结果之前写定。

**来源**：数据（同一个 `made_by`）、旧库。

**场**（补）：
- 网格随设计变的场（比如柄内多孔的密度）写成点集：每一行点数可以不同，每个点带坐标。
- 预测器学点集的场时，输入可以带点的坐标；预测时给坐标，出值。
- 预测的场可以当柄的材料回到 FEA，用了哪一份预测记进 `made_by`。
- 场的写法见《设定的声明和包的清单》第六节。

**冻结的评判**：
- 留出的不进训练；
- 误差怎么算；补上中位数、分位数、相对误差、在容差内的比例（补）；
- 缺的、重复的判不可判；
- 预测器不给区间时，覆盖率判不可判，不是 0（补）；
- 另取的测试集：用复核拿另登记的数据来比（补）；
- 不同 `made_by` 的数不混。

**和现在的差别**：
- 模型族现在是插件里的自由代码，超参数是一段 JSON，换模型族要改插件的代码。
- 场只能学每一行形状都一样的数组，预测器的入口只收骨、设计和条件（补）。

## 七、优化

**流程**（冻结的骨架）：
- 取候选：在柄空间的设计范围里，按取法取设计；交给柄空间包模板化（放不放得下、去多少骨）；得到候选池。
- 选点：选点策略包按目标、约束、数据、预测器选；可行性再核一遍（冻结的）；得到一批点，带理由和重放记录。

**包**：
- 柄空间包，做模板化。
- 选点策略包：已经是包，要补上声明的参数和默认值。
- 取法（拉丁超立方、Sobol、随机、围绕某点）作为声明过的设定，不用单独成包。

**设定**：
- 设计范围：照柄空间包的声明核对；
- 取法、个数、种子；
- 目标和约束：写在声明过的列上；
- 条件默认：照有限元设定里“每个点可以变”的项核对；
- 策略的参数：照策略包的声明。

**冻结的评判**：可行性怎么判；选出的点再核一遍；能重放。

**和现在的差别**：
- 取候选现在用的是“内核”的模板化；
- 条件默认是一段 JSON；
- 策略的参数没有声明。

## 八、四种实验共用的五件事

1. 核心管流程：新建、填、启动、轮询、停止、发布、记来历，照声明核验设定。
2. 插件管这种实验的流程骨架和评判规则（冻结），以及怎么跑（自由）。
3. 会变的做法是包：声明设定，带测试轮的默认值，按哈希定住。
4. 一次研究的取值是登记的设定，写全。
5. 来源是登记的数据。

和蓝图五条原则的关系：
- **只存三样**：不变。
- **只有一个写入者**：不变。
- **插件只交候选**：不变。
- **规则只有一份**：核验设定的规则只在核心里有一份。
- **固定的小**：冻结的只有流程骨架和评判规则，做法都进包。

## 九、目标：怎么算做成了

| 编号 | 目标 | 怎么算达到 |
| --- | --- | --- |
| M1 | 一套流程，多个柄空间 | 同一个 FEA 插件，用两个设计空间不同的柄空间包各算一批点，冻结的代码和插件都不改 |
| M2 | 改设定不改代码 | 同一组包，换骨（CAD 的 3406、一根 CT 重建的骨、一份 STL 骨）、换放置策略的参数、换一个 Abaqus 设定（比如切向改成拉格朗日、或者换单元类型），都只换登记的设定 |
| M3 | 处处有声明 | 每种实验的运行设定、每个包的设定都有声明；不合声明的设定在启动前被拒，并说出是哪一项；页面上每个设定项都来自声明 |
| M4 | 跑的就是记的 | 每一行数据都追得到四样包的身份、写全的设定、骨模型；跑的时候没有隐含的默认值 |
| M5 | 测试轮 | 每种实验都能用包的默认设定跑一轮测试；测试轮的产物和正式的分开 |
| M6 | 骨模型三种来源 | CT、CAD、STL 写出来是同一种骨模型；用的一方照声明核对 |
| M7 | 原项目只当参照 | M1-3406-v1 作为参照包还在，能在 3406 上重算出旧库的数（评估项） |
| M8 | 文献里的实验安排装得进去（补） | 照四篇文献推演的办法再走一遍：第三节卡住的 8 条都补上了，或者写明了为什么不收 |

## 十、从现在走过去（只排先后，每一步都要过检查、带反向测试）

1. **定格式**：设定的声明、骨模型、包的清单（种类变多了）。这些都是固定的部分，要你看。
   草案见 [设定的声明和包的清单](设定的声明和包的清单.md)、[骨模型的写法](骨模型的写法.md)。
   四篇文献推演查出的格式缺口，已经在这一步一并补进三份草案（补）。
2. **你整理设置项**：每种实验、每种包各有哪些设定项。有限元那部分照 Abaqus 的分组整理。
3. **拆原来的内核**：拆成柄空间包（柄的参数化和放置）和有限元包（照 Abaqus 的设定建模、求解、后处理）；M1-3406-v1 留作参照包。
4. **重建**：做成方法包，加上 STL 来源，骨模型照新的写法。
5. **代理**：模型族做成包。
6. **优化**：取候选改用柄空间包；条件默认照声明核对；策略补上参数的声明。
7. **测试轮**。
8. **页面照声明画表单**。

## 十一、要你定的

1. 包的种类变多了（柄空间、有限元、重建方法、代理模型），契约里的种类表要改。
2. 测试轮的产物进不进账。我建议进，但标成测试，不能拿来训练和选点。
3. [骨模型的写法](骨模型的写法.md)和[设定的声明和包的清单](设定的声明和包的清单.md)末尾，各自要你定的几件。
4. **统计放不放进系统**（补）：组间、成对的比较和检验，判据和误差报告里更多的指标。两条路：
   - 放进冻结的评判规则；
   - 明定“统计在系统外做，做完登记成报告”，写成规矩。
5. **没有骨的分析**（补）：只有柄的重塑、单胞的均匀化。是走 FEA（有限元包声明不要骨模型），还是另成一种实验？数据和预测器的适用范围按什么认“主体”？现在只认骨标识。这和《骨模型的写法》第八节的主体标识是同一件事。
6. **柄空间包的职责**（补）：从“柄的形状和放置”扩到“柄的模型和放置”，柄的区域、材料、面组、特征点都由它交出。这样扩行不行？
7. **四篇碰到的“1.0 不做的”**（补）：按 CT 值逐点赋材料、批量重建、比较模型的好坏。要不要改，你定。

（原来的第 1 件“内核拆成柄空间包和有限元包”，你已经认了，挪到第〇节。）
