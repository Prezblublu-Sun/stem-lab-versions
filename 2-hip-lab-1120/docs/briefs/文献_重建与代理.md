## 1. 阈值 A：自动标志点 / 轴线相对专家参考的允许偏差

### 1.1 建议（全部为【建议】，依据见 1.2–1.3）

三档判定：通过 / 复核 / 不通过。统计量取测试集（建议 ≥10–20 根股骨）的**中位数**，并要求**每一例**不落入"不通过"档。

| 前倾角（同一定义） | ≤ 3° | 3–5° | > 5° | 评估者间 2.7°（Sangeux 2015）；观察者内/间 0.8–2.9°（Kaiser 2016） |

**无噪声的 CAD / 复合材料股骨模型**（单一几何、算法确定性）可收紧：头中心 ≤ 0.5 mm，头直径 ≤ 0.5 mm，颈轴 ≤ 2°，骨干轴 ≤ 1°。厂商标称角度只作合理性检查，不作验收真值（定义不明，见 1.4）。

**测试协议建议**：

1. 参考值用同一专家 ≥3 次重复标注（或 ≥3 名专家）的中位点，并投影到骨表面（Fischer 2020 的做法）。单次标注的颈轴自身散布就有约 ±2.5°，会淹没被测算法的误差。
2. 专家在三维表面模型上标注，不在二维 CT 切片上标注（Castille 2024：二维 CT 的观察者间/内变异 9 / 8.7 mm，三维与 VR 最低）。
3. 角度量（CCD、前倾角）必须用与自动流程**完全相同的几何定义**从专家标志点计算。
4. 报告中位数、IQR、最大值，并做随机刚体位姿不变性测试（Fischer 2020：100 次随机位姿结果不变）。

### 1.3 推理

1. **容差不应小于参考值自身的噪声**。专家在三维模型上：头中心 0.3 mm、小转子 2.4 mm、大转子 3.7 mm（中位），颈轴各分量 IQR 约 4.5°。所以头中心可以要求到 1 mm，转子点要求 2 mm 就没有意义，颈轴参考必须取多次标注的平均。
2. **容差不应宽于成熟算法已达到的水平**。公开算法做到头中心 0.4 mm、颈轴中位偏差 ≤ 2°、全距 ±5.5°（Fischer 2020），角度 / 轴 < 2.0–2.5°（Cerveri 2010）。3° / 5° 的两档线恰好落在"成熟算法典型值"与"成熟算法最差例"上。
3. **几何推导（我的计算）**。轴由相距 B 的两点确定、每点独立误差 e 时，角误差约为 atan(√2·e / B)。颈轴基线（头中心到峡部质心）约 30 mm：e = 1 mm 对应 2.7°，e = 2 mm 对应 5.4°。骨干轴基线约 120 mm：e = 1.5 mm 对应 1.0°。这与上表"颈中心 ≤ 2 mm 配颈轴 ≤ 3–5°、骨干轴 ≤ 1.5°"是自洽的。
4. **下游后果**。颈轴误差 θ 直接变成短柄的置入角误差；在 50 mm 力臂处位移为 50·tan θ：3° 是 2.6 mm，5° 是 4.4 mm（我的计算）。文献显示 2–3° 内翻已显著改变应力分布，可行域内的位置变化可使峰值微动增加 50%（约 0.18 dex）。因此颈轴 > 5° 的误差会产生与阈值 B 的代理模型误差预算同量级甚至更大的输出变化。
5. **转子点是区域性标志**，专家自己的最大误差就达 9–25 mm。若流程只用它们做区域标记，5–6 mm 足够；若用来定截骨高度，应直接对"截骨高度"这个导出量设容差（例如 ±2 mm，【建议】），不要依赖单点。
6. **重建精度约 0.5–0.8 mm**（CT），所以任何点位容差低于 0.5 mm 都只对 CAD 模型有意义。

### 1.5 不同意见与判断余地

- **"自动与人工有显著差异但很小"是否可接受，取决于用途**。Fischer 2020 明确写：≤ 0.5° 的坐标系差异"可能在临床上无关紧要"，但建议使用者按具体应用自行评估。
- **参考值本身不可靠**。Fischer 2020：人工颈轴散布大，"在表面模型上人工识别颈峡部不可靠"。因此颈轴的"专家参考"可能比算法更差；可以考虑用几何构造（最小截面质心连线）作为第二参考。
- **角度没有唯一定义**。同一股骨的前倾角随方法可差 5–20°（Sugano 1998；Kaiser 2016；Schmaranzer 2020；Van Fraeyenhove 2023；Scorcelletti 2020）。跨定义比较的容差没有意义。
- **分割 / 重建的操作者差异**也进入误差（Renault 2018）；本简报的容差假定自动与人工用同一个表面模型。
- **仍属判断的部分**：三档线的具体数值；峡部沿轴位置容差（无文献数字）；转子点容差是否要按用途收紧；测试集大小。文献里常见的是 20 根股骨左右（Fischer 2020；Cerveri 2010），Phan 2015 用 35 根。

## 2. 阈值 B：FE 代理模型的可用误差线

### 2.1 建议（全部为【建议】，依据见 2.3–2.4）

误差在 log10 输出上计算，单位 dex。留出集不参与训练和超参数选择，建议 ≥ 30 个点且 ≥ 总样本的 20%。

#### (i) 留出误差（插值）

| 档位 | RMSE | P95 绝对误差 | R²（log 尺度） | 含义 |
|---|---|---|---|---|
| 良好：可做定量预测和设计排序 | ≤ 0.05 dex | ≤ 0.10 dex | ≥ 0.90 | 约 ±12%；在 100–150 µm 处约 ±11–18 µm，落在"10–20 µm 或更好"的精度要求内（Viceconti 2000） |
| 谨慎可用：筛选、趋势、带不确定度的贝叶斯优化 | ≤ 0.10 dex | ≤ 0.20 dex | ≥ 0.80 | 约 1.26 倍；与已发表的微动 GP 代理模型相当（RMSE < 20 µm、R² = 0.81，Al-Dirini 2020） |
| 不可作预测器 | > 0.15 dex | — | < 0.80 | 1.41 倍；已模糊掉 50→150 µm 窗口（0.48 dex）的三分之一 |

补充条件：

- **按输出区分**：
  - 界面微动：采用双重判据，单点误差 ≤ max(0.05 dex, 10 µm) 记为良好，≤ max(0.10 dex, 20 µm) 记为谨慎可用。低微动区（< 40 µm）远离任何骨长入阈值，用 dex 判据会过严。另查 50 µm 和 150 µm 两条线两侧的分类一致率 ≥ 90%。
  - 植入物转角：同样的 dex 线，绝对值下限用 0.02°（良好）/ 0.05°（谨慎）。文献依据薄弱，见 2.5。
  - 骨切除体积：纯几何、确定且光滑，应明显更好：RMSE ≤ 0.02 dex、R² ≥ 0.98；达不到时先怀疑流程有错。
  - 场代理模型：高于下限（如 > 20 µm）的节点中位相对误差 ≤ 10%；峰值误差按上表；超过 50 / 150 µm 的面积比误差 ≤ 5 个百分点。
- **对照 FE 自身的数值噪声**：选 ≥ 10 个设计，改网格密度 / 接触参数重算，得到 σ_FE（dex）。留出 RMSE² ≈ 模型误差² + σ_FE²，代理模型不可能也不需要低于 σ_FE。若 σ_FE 已接近 0.05 dex，应先改进 FE，或用带 nugget 的回归型 GP。
- **对照设计之间的差异**：R² ≥ 0.9 等价于 RMSE ≤ 0.32 × 设计间标准差。两个设计的预测差要超过约 2.8 × RMSE 才能在 95% 水平上分辨（我的推导：1.96·√2）。RMSE = 0.05 dex 时是 0.14 dex（1.38 倍），RMSE = 0.10 dex 时是 0.28 dex（1.9 倍）。
- **按极差归一化的 NRMSE ≤ 10% 只能作必要条件**。输出跨 2 个数量级时，10% 就是 0.2 dex。
- 任何留出点误差 > 0.3 dex（2 倍）都应单独检查对应的 FE 运行是否收敛。

#### (ii) 外推 / 留一组交叉验证（留一根骨、留一个设计族、留一个载荷工况）

| 档位 | LOGO RMSE | 与留出 RMSE 之比 | 处置 |
|---|---|---|---|
| 可外推 | ≤ 0.10 dex | ≤ 2 | 可在未见组上使用 |
| 有限外推 | 0.10–0.20 dex | 2–3 | 只在带不确定度的决策中使用；最优点必须用 FE 复算 |
| 不可外推 | > 0.20 dex，或任一组 > 0.30 dex | > 3 | 代理模型只在训练过的组内有效；新组需要补 FE 样本 |

另要求每组的平均带符号误差绝对值 ≤ 0.5 × RMSE（没有整组偏移）。

#### (iii) 预测区间覆盖率

| 指标 | 接受范围 |
|---|---|
| 95% 区间的经验覆盖率（留出，n ≥ 100） | 90%–99% |
| 90% 区间 | 84%–96% |
| 50% 区间 | 40%–60% |
| 标准化残差绝对值 > 3 的比例 | ≤ 1%（n < 100 时不应出现） |
| 标准化残差的均值 / 标准差 | 均值在 ±0.3 内；标准差 0.8–1.3 |
| LOGO 下 95% 区间覆盖率 | ≥ 85%；否则先重新校准再用于优化 |
| 锐度：95% 区间半宽 | ≤ 0.3 dex；更宽则分不开 50 与 150 µm |

覆盖率范围按二项抽样误差给出（我的计算）：名义 95%、n = 100 时标准误 2.2%，n = 50 时 3.1%，n = 200 时 1.5%。

**样本量起点**：n ≈ 10 × 输入维数（Loeppky 2009；Jones 1998）。达不到 R² ≥ 0.8 时加点，不要放宽线。

### 2.4 推理

1. **物理锚点**。骨长入的"安全"与"失败"之间隔着 20–40 µm 到 150 µm，约 0.5–0.9 dex。要在这个窗口内区分设计，方法精度需 10–20 µm（Viceconti 2000）。在 100–150 µm 处，这等于 0.03–0.10 dex。所以 0.05 dex 是"良好"线，0.10 dex 是可用的上限。
2. **同行水平**。已发表的微动代理模型做到 RMSE 14–20 µm、R² ≈ 0.8，作者称之为很好；应力 / 应变类光滑输出做到 1–10%、R² 0.83–0.99。10% 相对误差是 Cilla 2017 明确使用的接受线，等于 0.041–0.046 dex。
3. **上游误差封顶**。FE 自身对实验的误差约为峰值的 7–12%（约 0.03–0.05 dex），实验系统误差可达几十微米，试样间刚度变异 < 10%。代理模型误差压到 0.02 dex 以下没有物理意义。
4. **比低 RMSE 更重要的是不确定度可信**。优化用的是"预测 + 不确定度"；Jones 1998 的判据就是标准化残差落在 ±3 内。所以覆盖率和 RMSE 并列为验收项。
5. **外推必须单独验收**。文献里的微动 GP 是每根股骨都给了训练点的；独立个例的 R² 比模型内实例低约 0.1。随机留出会高估对新骨、新设计族的精度。

### 2.5 不同意见与判断余地

- **没有通用的微动阈值**（Kohli 2021）。因此"10–20 µm 精度"的前提（阈值在 100–200 µm）本身不确定到 2–3 倍；只做设计间相对排序时，0.10 dex 也许已经足够。
- **R² 的线是惯例**：同一本书被引为 0.8 和 0.9 两种说法。我取 0.8 为下限、0.9 为良好。
- **微动比应力场难得多**。Liang 2018 的 < 1% 误差出现在光滑、低维形状空间的问题上；含摩擦接触的微动不应以它为期望值。
- **FE 自身的有效性是上限**（Pettersen 2009："成功有限"）。如果 FE 未经实验确认，再严的代理模型线也只是对 FE 的忠实度。
- **样本量**。Loeppky 2009 指出对难题，超过 10d 后精度提高缓慢。达不到线时，可能要改输入参数化或输出变换，而不是一味加点。
- **仍属判断的部分**：三档线的具体数值；绝对值下限（10 / 20 µm、0.02° / 0.05°）；LOGO 的倍数线（2 和 3）；覆盖率范围；分类一致率 90%。植入物转角的线几乎没有文献支撑。监管语境下应按"使用情境 + 风险"来定可接受阈值（Viceconti 2021），而不是套通用数值。
