## 现在是什么样

- **旧内核包**（`external/kernel_m1_3406`）：是原项目代码外面的一层薄壳。
  - 构建时，`build.py` 从只读的原项目里把几个文件复制进包里的 `legacy/`：`model3d_m1.py`、`fe3d_geom.py`、`post_m1.py`、`geom3d.py`、`femur_real.py` 等。
  - 能做的事：模板化（`template`）、建模（`build`）、后处理（`post`），另有 `bench`、`selfcheck`。
  - 设计项 14 个、条件 8 个，写在包的清单里。只认 `sawbone3406` 这一根骨。
  - 在原项目里，柄的几何和有限元建模是揉在一起写的：建模那一步从设计项重新生成柄。
- **FEA 的骨架**（`plugins/fea/plugin.py`，冻结）：把“怎么算”绑在两样输入上，内核和推导量定义；导出设定一份，运行设定也混在里面。

## 改成什么样

照《核心》第四节：FEA 只有一套流程，每个点走这几步：
1. 柄空间包模板化，交出柄的模型；无植入物时跳过。
2. 有限元包建模。
3. 求解，排求解槽。
4. 后处理。
5. 推导量。
6. 交数据。
7. 判判据。
8. 归档。

输入表：

| 输入 | 说明 |
| --- | --- |
| 骨模型 | 第 1 版照旧；有限元包也要读得懂第 2 版（第 5 步开始写） |
| 一批点 | 第 2 版：条件、放置、推导量三组每个点给 |
| 柄空间包、放置设定 | 柄空间包可以不填，不填就是无植入物 |
| 有限元包、有限元设定 | 设定照有限元包的声明，按 Abaqus 分组 |
| 推导量定义包、推导量设定 | |
| 运行设定 | 求解槽、超时，不进 made_by |
| 判据 | 可选 |

数据的 made_by 写第 2 版：`stem`、`fem`、`derive`，三份设定的哈希，骨模型的版本。

## 分几小步

| 小步 | 做什么 | 怎么算做完 | 要不要 Abaqus |
| --- | --- | --- | --- |
| 4a | FEA 的骨架两条路都走得通：填参照包（旧内核），或者填柄空间包加有限元包。核心核过的设定，骨架再核每个点给的项（第 6 条）和名字引用（第 8 条） | 用测试包走通：一个假的柄空间包、一个假的有限元包；参照包那条照旧；无植入物那条也走通 | 不要 |
| 4b | 照现在的设定写声明：原内核清单里的设计项和条件、导出设定里的各项，带上测试轮的取值和来路；运行设定另成一份 | 声明过 A 批的规矩；测试轮的设定拼得出来 | 不要 |
| 4c | M1 的柄空间包：从原项目的代码里拿出参数化、模板化、放置，交出柄的模型（B 批的格式） | 3406 上模板化的结果和参照包一样；交出的柄的模型过契约的核对 | 不要（几何用 gmsh/OCC） |
| 4d | Abaqus 的有限元包：读骨模型和柄的模型，照有限元设定建模、求解、后处理 | 3406 上，柄空间包加有限元包算出的数和参照包一样（科学验收，在容差内） | 要 |
| 4e | 推导量定义包改用名字引用取值的位置（比如照柄轴、柄尖划 Gruen 区） | 和原来算出的推导量一样 | 不要 |

4a、4b 是框架，先做。4c、4d 是真拆原项目的代码，量最大；4d 要在这台机器上用 Abaqus 跑。

## 要你定的

1. **参照包怎么跑**。我的建议：FEA 照旧收“内核”这一样输入，作为另一条路，只给参照包用，算出的数 made_by 里是 `kernel`；新的路收柄空间包加有限元包。另一种办法是参照包单独成一种实验类型。
2. **拆完以后算得对不对，以什么为准**。我的建议：在 3406 上，拆出的两个包和参照包算同一批点，标签和推导量都在一个容差里（容差你定，写进 `tests/science/lines.py`）。这是拆内核这一步的验收，和“科学验收只评估、不挡发布”不矛盾：它比的是拆之前和拆之后，不是和实验比。
3. **第 4 步在哪个会话里做**。这个会话已经很长了，要做的是拆原项目的代码。新开一个会话做，读这份文档和《改格式的分批》就能接上，上下文更干净。
