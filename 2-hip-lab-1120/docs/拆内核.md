1. 出柄的模型：柄空间包的 `model`，交出柄的模型（B 批的格式）和模板化的量；无植入物跳过。

3. 推导量：推导量定义另拿到骨模型、柄的模型、这个点的推导量设定，4e 用名字引用取位置时要用。
4. 交数据、判判据、归档，照旧。柄的模型和柄空间包的记录也归档。

**骨架启动前核的**（冻结，新文件 `plugins/fea/given.py`）：

| 项 | 类型 | 测试轮的取值 | 是什么 |
| --- | --- | --- | --- |
| `zone_from` | 名字引用：骨的标志点，或柄的特征点 | `bone.landmark.head_center` | 深度从哪个点量起 |
| `zone_offset_mm` | 数，mm | 16 | 上面那个点先沿深度轴往远端挪这么多，才是参照点 |
| `depth_axis` | 名字引用：柄的轴 | `stem.axis.neck_axis` | 深度沿哪根轴量：逆着轴的方向（往远端）为正 |
| `zeta_max_mm` | 数，mm | 15 | 支撑区到参照点以下多深为止 |
| `angle_axis` | 名字引用：柄的轴 | `stem.axis.stem_axis` | 角度绕哪根轴量 |
| `angle_from` | 名字引用：柄的轴 | `stem.axis.neck_axis` | 0 度朝哪：这根轴的方向投到垂直 `angle_axis` 的面上 |
| `theta_max_deg` | 数，度 | 45 | 支撑区在 0 度两侧各多少度 |
| `t_floor_mm` | 数，mm | 0.25 | 泡沫厚度的下限：比它薄的按它算 |

- 四个数可以每个点给；四个名字引用所有点都一样。
- 每项的来路写在声明里：`bed_f.json` 的哪一项，旧系统里它的出处。

**怎么算**（算法照旧，变的只是位置从哪来）：F = 对柄身（不在领上）的界面节点里落在支撑区内的，求 面积 / max(泡沫厚度, 下限) 之和。
- 泡沫厚度是点云里的 −`d_canal`。
- 深度 ζ：从参照点起，逆着深度轴量。
- 角 θ：节点绕 `angle_axis`、从 0 度方向量的角。
- 支撑区：ζ ≤ `zeta_max_mm`，而且 |θ| ≤ `theta_max_deg`。
- 坐标：柄的特征点和轴在柄自己的坐标系里，照柄的模型的 `placement.frame` 换到骨模型的坐标里；骨的标志点、4d 的界面点云本来就在骨模型的坐标里。

**包的清单**：照改格式以后的写法，带 `programs`（空的：不用外部程序）、`declarations`（上面那份）、`modes`、`inputs`（要骨模型、柄的模型、界面点云里的什么）、`needs`、`columns`。
