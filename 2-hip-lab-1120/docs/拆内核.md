## 改成什么样

照《核心》第四节：FEA 只有一套流程，每个点走这几步：
1. 柄空间包模板化，交出柄的模型；无植入物时跳过。
2. 有限元包建模。
3. 求解，排求解槽。
4. 后处理。
5. 推导量。
6. 交数据。
7. 判判据。
8. 归档。

输入表：

| 输入 | 说明 |
| --- | --- |
| 骨模型 | 第 1 版照旧；有限元包也要读得懂第 2 版（第 5 步开始写） |
| 一批点 | 第 2 版：条件、放置、推导量三组每个点给 |
| 柄空间包、放置设定 | 柄空间包可以不填，不填就是无植入物 |
| 有限元包、有限元设定 | 设定照有限元包的声明，按 Abaqus 分组 |
| 推导量定义包、推导量设定 | |
| 运行设定 | 求解槽、超时，不进 made_by |
| 判据 | 可选 |

数据的 made_by 写第 2 版：`stem`、`fem`、`derive`，三份设定的哈希，骨模型的版本。

## 4a：两种实验，一套流程

**目标**：`fea.reference` 照旧；`fea.run` 收柄空间包加有限元包，有植入物、无植入物都走得通。
核心核过的设定（第 1 到 5、7、9 条），骨架再核每个点给的项（第 6 条）和名字引用（第 8 条）。

**`fea.run` 的输入表**：

| 输入 | 收什么 | 必填 | 说明 |
| --- | --- | --- | --- |
| `bone` | 骨模型 | 是 | 第 1 版照旧 |
| `points` | 一批点 | 是 | 第 2 版 |
| `stem` | 柄空间 | 否 | 不填就是无植入物 |
| `placement` | 设定 | 否 | 填了柄空间才填，照它的 `placement` 声明 |
| `fem` | 有限元 | 是 | |
| `fem_setting` | 设定 | 是 | 照有限元包的 `fem` 声明 |
| `derive` | 推导量定义 | 是 | |
| `derive_setting` | 设定 | 否 | 推导量定义声明了 `derive` 才填 |
| `run` | 设定 | 是 | 照这种实验自己声明的运行设定 |
| `criteria` | 设定 | 否 | 判据，照旧 |

**每个点**：
1. 出柄的模型：柄空间包的 `model`，交出柄的模型（B 批的格式）和模板化的量；无植入物跳过。
2. 建模、求解、后处理：有限元包的 `build`、`post`，中间排求解槽。有限元包拿到的是骨模型、柄的模型、这个点的有限元设定（设定里写的，加上这个点给的）。
3. 推导量：推导量定义另拿到骨模型、柄的模型、这个点的推导量设定，4e 用名字引用取位置时要用。
4. 交数据、判判据、归档，照旧。柄的模型和柄空间包的记录也归档。

**骨架启动前核的**（冻结，新文件 `plugins/fea/given.py`）：
- 几份设定都照声明写，照的是对的那一份：放置设定照这个柄空间包的 `placement`，有限元设定照这个有限元包的 `fem`，推导量设定照这个推导量定义的 `derive`，运行设定照 `fea.run` 的 `run`。
- 第 6 条：每个点的设计项照柄空间包的 `design` 写全、合规矩；条件、放置、推导量三组照三份设定里写了“每个点给”的项。无植入物时设计和放置两组是空的。
- 第 8 条：名字引用照骨模型和柄的模型里有的名字核。柄的模型要到跑的时候才有，所以柄空间包在清单里先写明它交出的柄的模型里一定有哪些名字（`names`），启动前照这个核；跑的时候再核交出的柄的模型合格式、名字都在，不合的作业归成出错。
- 数据说明拼得出来：设计项、三组每个点给的项、柄空间包和有限元包的产出、推导量，列名不重复；每个点给的项要写进数据的行，只能是数、整数、是否、几选一、文字。

**made_by**：`kernel` 是 null；`stem` 记柄空间包（无植入物写 `"none"`），`fem` 记有限元包；三份设定里所有点都一样的那部分各记哈希；骨模型的版本。

**跟着改的固定部分**：
- 契约：插件可以声明自己的设定（`Kind.settings`，就是运行设定）；made_by 的新写法；骨模型第 1 版能给出名字引用用的名字；包的清单里写上柄空间包、有限元包和叫它们的一方的约定，柄空间包的设计项每一项都由一批点给。
- 核心：启动时照声明核设定，也认照实验类型声明的那几份。
- 挂点的门面：跑柄空间包、有限元包，和骨架要用的几个核对的函数。
- 测试：一个假的柄空间包、一个假的有限元包；`fea.run` 的验收情形；原来的 FEA 情形改到 `fea.reference` 上跑，情形本身不改。

**怎么算做完**：
1. 原来的 FEA 验收情形在 `fea.reference` 上照过，换写法的那一条也照过。
2. `fea.run` 用两个假包走通：有植入物、无植入物各一批点，数据、归档、made_by 都对。
3. 第 6、8 条，和几份设定照错了声明，各有一个只违它的情形，启动前被拒，说出是哪一项。
4. 柄空间包说放不进去、交出的柄的模型不合格式、少了清单里说的名字，各归到对的结局。
