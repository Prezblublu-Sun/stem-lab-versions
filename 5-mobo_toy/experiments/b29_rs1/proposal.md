# 提议：b29 RS-1，环带空间填充

**状态：** 2026-11-08，五天计划的一批（`experiments/plan_5day_2026-11-08.md`），用户"整份批准"。

| 项 | 值 |
|---|---|
| 目的 | 给离 A 0.25 到 0.75 的环带补一批不按代理挑的行：检验代理在环带的真实误差，补上"种子不代表空间"的缺口 |
| 绑定的交付物 | D3（代理验证）；D7 |
| 行数 / 槽时估计 | 48 行，只解摩擦，约 15 到 26 槽时 |
| 属于"细化候选"吗 | 否 |
| 依赖 | A 的 m 1.0 版 DONE；不要钩子 |
| 判据 | G46 |

## 行

从 b28 的环带候选（6000 个点 × e 0、+1、+2，生产模板化可行的 8659 对，m ≥ 1）里，去掉和 b28 的行重合的，用种子 56202 不看分数随机抽 48 对。离 A 0.26 到 0.75，中位 0.38；e 0 有 19 行、+1 有 17 行、+2 有 12 行；去骨 4.2 到 10.1 cm³。没有做放置检查，因为这批代表的是"可模板化的环带"这个总体。行在 `experiments/prep_2026-11-08/data/rs1_rows.json`，脚本 `select_rs1.py`。

候选池怎么来的：`b28_fam/prep/ring_inputs.py`，种子 56103，13 维随机方向，半径在 0.25 到 0.75 里均匀，留在盒内且 m ≥ 1，没有用代理预筛。半径均匀不是体积均匀，内圈的点更密。

来源记 corner：环带是按 A 定的子区，性质和 CR 角落层一样，进排除集 E，不进严格无偏集。al_problem 叫 `F_f1_bone_ring_rand`，不叫 iid，免得以后当成全空间的无偏样本。

## 判据（看结果前写定，第二模型审查后改）

**G46：** b28 代理（选点时冻结的预测）在有微动的行上 log10 RMSE ≤ 0.07 dex，且标定后 90 % 区间覆盖 ≥ 0.70，覆盖的分母是 48，没有微动的行算没覆盖。有行没提交或没算完，判不适用（批还没算完）；算失败、缺微动或 tag 重复的行超过 8 行，判不适用。
- 过：在环带的随机总体上，代理的误差和标定区间可信，可以靠代理在环带排序再用 FE 核对。不外推到代理挑出的最优点、可放置的子集和 R2 的重训版。
- 不过：环带上代理的误差比标定的大，环带要继续靠 FE 铺点。
- 描述，不判：预测 ≤ 1.6（40 µm）的子集；缺行取最坏误差时 RMSE 的上界；按入口偏移分开；R2 用的重训版的误差（预测在喂料前冻结，`pred2_rs1.py`）；每行相对 A 族曲线的 ΔF、Δlog 微动，有几行按 b28 的路线超过 A 族。放置检查结果后补，只用来把误差按可放置和不可放置分开报。
