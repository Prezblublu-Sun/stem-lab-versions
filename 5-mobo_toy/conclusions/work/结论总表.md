## 5 口径

| 项 | 取值 |
|---|---|
| 转动 | 生产 `stability` 的 `rot_first_deg`，首次加载的刚体拟合 |
| 倍数 | 设计转动 ÷ 对照转动；dex = log10(倍数) |
| 噪声 | ±0.012 dex 内不解读 |
| 盒内 | v1 设计空间，α ≤ 45°、L ≤ 45、m 0.5–2.0 等 13 个变量 |
| 代价曲线 | 严格基线，加偏移固定为 0 的 L 扫描；折线只算盒内 |
| 单因素 | 只改一个量，其余等于设计 A；L 行偏移固定为 0；α 行的号和偏移由模板重选 |
| 配对 | 同一设计相对自身严格基线行，用 12 个连续设计变量匹配 |
| 前瞻误差 | log10(FE) − 冻结的 GP 均值，改载荷的行不算；覆盖按 \|z\| < 1.645 |

逐行数字在 `data/`，图在 `figures/`。
