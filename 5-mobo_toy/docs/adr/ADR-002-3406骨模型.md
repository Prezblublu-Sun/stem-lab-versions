# ADR-002 骨模型用 Sawbones 3406（Churun 的未切割 CAD，右侧化烘焙）

**定于** 2026-10-22 用户："must use Sawbones 3406"；10-23 用户确认 `churun` = 实验室的 3406；10-24 00:10 用户"按你建议的继续"采纳颈轴 isthmus 和 v2 松质芯。

## 背景
10-23 前的全部工作在一根 CT 股骨（右侧、431 mm、Dorr A，`260429 test 2bones`）上。台架要用 3406，所以模型要换到同一型号。全盘搜索没有找到带 3406 标签的文件；Churun 的切割件是同一根骨但头颈已切；未切割件在 OneDrive（Parasolid，2026-01-21）。

## 决定
- 几何：Churun 的未切割 3406（左股骨）→ SolidWorks 转 STEP → `bake_3406.py` 只把 z 取反得到右股骨（x 内侧、y 后方、z 近端），与哈希代码的约定一致；松质芯导针孔填掉（v2 芯，ream-and-refill，使完整股骨能划网格）。
- 颈轴：isthmus 法（112.4° / −3.8°），不用检测器（在 3406 上落在转子区）也不用 README 的 127°。
- 登记：`femur_id = sawbone3406`，`femur_geom_key 9281cd8eac10eace`，同 id 不许换键。
- 材料按 Sawbones：皮质 16 800 MPa，松质 155 MPa，Ti 110 000。

## 被否的方案
- 继续用 CT 股骨：与台架不是同一件，排序无法对照。
- 厂家公开 STEP（10-23 下载）：只有外表面，没有皮质/松质分界和髓腔，只能用来补头颈。
- Bath F10 网格：实测是 3403 中号，不是 3406。
- README 的颈轴（127° / 17°）：不可复现。
- A 系变换 diag(1, −1, −1)：保持左手性、+y 变前方，会让髁检测和载荷符号都错。

## 后果
- 3406 的松质芯宽、泡沫软，同一柄比 CT 股骨微动高 6 倍、转动高 9 倍；阶段 10 的设计在 3406 上全部不可行，设计空间改为 h_cut 16–32、L ≤ 45。
- 只有一根 CAD，不是实物 CT；台架前要对实物做 CT 建第二根骨（ADR 待写）。
