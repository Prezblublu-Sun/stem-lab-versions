# 词表

新会话读 `STATE.md`、计划和批次名时会碰到的缩写。只解释，不下判断；口径以 `db3406/DATA_CARD.md` 第 3 节为准。

## 量与单位

| 词 | 意思 |
|---|---|
| dex | log10 的倍数差。+0.209 dex = 1.62 倍。两设计转动之比取对数；±0.012 dex 内不解读（网格噪声 2 倍 rms 0.010 dex） |
| 槽时 | 一个求解槽（Windows worker 的 1 槽 = 5 核）跑 1 小时。3 槽 × 24 h = 72 槽时/天，一周约 428 槽时可用。一行摩擦作业约 0.55 槽时（h 2.0），h 1.4 约 1.0，10 循环约 1.4。来源：`worker.log` 里每个单元的 `OK <秒>` |
| 转动 rot_first / rot_rev / rot_perm | 首次加载 / 第二循环可逆 / 卸载后残留的刚体转动（度），柄相对骨 |
| 微动 f1_p95 | 第二循环界面切向相对位移的面积加权 P95（µm） |
| 完全接触面积 | 界面间隙 ≤ 1 µm 的面积（mm²） |
| SED 变化 sed_chg_pct | 股骨距 G7 区皮质应变能密度相对完整股骨的变化（%，负 = 应力屏蔽） |
| 去骨 bone_total | 截骨 + 锉骨体积（mm³ 或 cm³） |
| 无偏集 unbiased | 准随机采样、不在 E 里的行，可当 iid 样本报指标；E = 被优化器或分层选点"看过"的设计键集合，报指标时排除 |

## 设计量（13 个，无领柄）

| 符号 | 意思 |
|---|---|
| L | 柄长 mm |
| alpha, α | 冠状面内柄轴与干轴夹角，度（上限 45° 在最优区贴边） |
| h_cut | 截骨深度，距头心 mm（16–32，16 贴边） |
| m | 余量：柄到皮质至少留 m mm 泡沫（0.5 贴边；手术可达约 ≥ 1.0） |
| q | 锥度指数（3.0 贴边 = 近似等截面） |
| lam, λ | 截面长宽比 |
| g_ml, g_ap | 截面在内外 / 前后方向的形状参数 |
| n_a, n_p | 前 / 后半截面的超椭圆指数 |
| tau_a, tau_p | 前 / 后半截面的扭曲 |
| rho_tip | 尖端圆角比 |
| e | 入口偏移 mm：模板化时柄入口沿截骨面的平移；生产规则按 2 mm 档选 A0 最大的一档（多为 0），`entry_offset_forced` 行是人为固定的 e |
| A0 | 模板化得到的肩部面积 mm²（由贴合决定，不是自由变量） |

定义在 `v2/geom3d.py`（冻结文件）。

## 条件与保真度

| 词 | 意思 |
|---|---|
| δ, delta | 松质过盈 mm（基线 0.10，暂定；变体 0.025 / 0.05 / 0.20） |
| μ, mu | 界面摩擦系数（基线 0.3；变体 0.2 / 0.15） |
| 楼梯 / 2391 N | 基线头力：合力 2391 N，α_front 20°、α_sagit 18°。变体 F3839 = 3839 N，F3606，起身 1714 N，S40 = 矢状角 40° |
| h 2.0 / h1.4 / h2.4 | 界面网格尺寸 mm（保真度）；h 1.4 是"重作业" |
| c10 / cycles | 加载循环数（基线 2；变体 4、10） |
| M1 | 现行摩擦界面模型（面对面接触 + 压配），对应 `model3d_m1.py` |
| 粘接 bond | 同网格 `*TIE` 模型，只为 SED 和柄应力 |
| 完整股骨 intact / REF 行 / `db_ref_*` | 没有柄的参照作业，SED 变化的分母。**与 REF-1 不同**：REF-1 是"同模型参照柄"实验（在 3406 上算一个已上市的柄）；`DB_H14_REF_OK` 里的 REF 指 h 1.4 的完整股骨参照已算好 |
| heavy / light 模式 | 喂料器对 h 1.4 重作业的排队方式：heavy = 一次只放一个重作业、旁边可有轻作业；`DB_H14_EXCLUSIVE` 存在时重作业独占 |
| `DB_RELEASE_<层>` | 某层被失败门挡住后，用户授权放行的标记（如 `DB_RELEASE_AL-3m`、`DB_RELEASE_SF-1`） |
| 队列计数 | `STATE.md` 的 NEW/READY/CLAIMED/SOLVED/DONE/FAILED 是队列目录里标记文件的累计个数，一个作业可同时有 CLAIMED、SOLVED、DONE；FAILED 含 prep 阶段失败（L3）的作业，它们从未 SOLVED，所以 DONE + FAILED ≠ SOLVED 是正常的 |
| `m_fric` / `m_bond` | 一个作业里的求解单元：摩擦模型 / 粘接模型的 inp |
| TA10 / TB10 | 扭转冒烟：定义 A / B，10 N·m |
| "db_* rows adopted by a later batch" | 导出器 0.2.3 的说明：一个作业被两个批次清单引用（后一批查重时采纳了前一批已有的作业） |
| QA 14 条检查 | `tools/db_qa.py` 的检查，清单在 `db3406/DATA_CARD.md` 第 9 节；1、7、13 条的已知失败行在 `ops/qa_baseline.json` |
| G11 / G12 | 第三版第 7 节：VAL-1 实测对仿真的判级 / REF-1 参照柄的判级 |
| Z5 / Z7 | 第三版第 4 节：Gate 1 证据包与验收门改写 / 代理验证报告 |
| Gate 1 | 博士计划（2026-02 的 Plan and Timeline）的第一个里程碑：冻结 FE 模型 + 种子数据集 + 代理验证 + 实测对仿真；约 2026-12 中，日期要导师确认；与 MPhil→PhD upgrade 的关系未定 |
| 带领 collar | 柄在截骨面上的领座；10-10 决定无领，COL-1 是条件批次 |
| PINN | 物理信息神经网络，用户 10-28 想试，放到 Gate 1 之后 |
| Churun | Churun Lin，同组同学，3406 未切割 CAD 的来源 |
| Naghavi | 同组博士论文（2023），同型号 3406 的实测应变和 FE，VAL-1 的对照来源 |

## 名字怎么读

| 样子 | 意思 |
|---|---|
| `p11` `p13` `p14` | BO 阶段号（`stage_neckopt` 的 phase）；p13 两目标臂、p14 三目标臂 |
| `sb13_a105_91e458e3` | 阶段 13 异步选点第 105 个，`91e458e3` 是规格 hash8；设计 A = `p13_a105_91e458e3` |
| `a95` `a82` `a96` `a100` | 与 A 同一族的第 2–5 名 |
| `b1` … `b24` | `stage_db.py` 的批次号（喂料单位，有清单 `results/db_manifest_b*.json`） |
| `b7m` = AL-3′ = round `al3m` | 主动学习第 3 轮按 m ≥ 1.0 重选后的批次 |
| 层 layer：SF-1、CR-1、CR-T、CD-1/2、NZ、FD-0/1、BD、WS、WL、OW、AL-n | 数据库的分层：Sobol 填充、角落、角落留出测试、条件集、噪声、保真度、粘接、m/α 扫描、L 扫描、偏移窗、主动学习 |
| 行名 `TQ1S_A_e+1.5`、`PF1S_e0_de-1`、`OW4_S40_e+2` | 批次内的行标签：TQ1S = 扭转冒烟（A/B 两种定义，TA10 = 定义 A 10 N·m），PF1S = 放置冒烟（de = 入口偏移误差 mm），OW3/OW4 = 偏移窗第 3/4 批，后缀是条件 |
| `db_cd_…`、`db_ws_…`、`db_fd_…` | 作业 id 的 stage 前缀：cd 条件、ws 窗扫描、fd 保真度、al 主动学习、crt 角落留出、ref 参照 |
| 冒烟 smoke | 只跑几行验证钩子或流程可用，不下结论 |
| TQ-0 / TQ-1 / PF-1 / MU-1 / VAL-1 / REF-1 / FY-1/2 / SF-2 | 计划里的实验名：头力扭矩扫描 / 纯扭转 / 放置 / 摩擦 / 实测对仿真 / 参照柄 / 泡沫屈服 / 第二批 Sobol |
| Z1 … Z12 | 第三版计划第 4 节的 0 FE 工作项 |
| G1 … G35 | 第三版计划第 7 节的分叉判据，结果出来前写定 |
| D1 … D8 | `docs/goal.md` 的交付物 |

## 机器与角色

| 词 | 意思 |
|---|---|
| serve | Linux 常驻：NEW → prep（建模、模板化、划网格）→ READY；SOLVED → post → DONE |
| feed / 喂料器 | Linux 上按批次清单把规格写进队列的进程（`stage_db.py feed <b>`） |
| worker | Windows 上领 READY、跑 Abaqus、推回结果的进程（`solve_worker.py`） |
| `DB_RELEASE_*`、`STOP_DB_FEED*`、`DB_H14_*` | Linux 上的操作标记文件，见 `docs/runbook.md` 第 4 节 |
| j / j/master | J: 盘上的裸仓库远程（备份） |
| VERSION 里的 12 位 code_hash | `remote.py` 对整个同步文件列表算的哈希，与 10 位的作业 `code_hash` 不是一回事 |
| 实验会话 | 唯一能改 `v2/`、`tools/`、部署、喂料、提交的会话（现为"股骨柄项目评估"） |
| 重组会话 | 2026-11-04 起做重组第 0–4 步的会话，只改 `docs/ ops/ experiments/ conclusions/` |
| 汇报会话 | 只写 `conclusions/`，不参与实验 |
| 重组第 0–5 步 | 见研究日志 `项目重组提议_2026-11-04.md` 第 7 节 |
