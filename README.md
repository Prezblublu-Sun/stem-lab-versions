# stem-lab 的几个版本

stem-lab 是一个管股骨柄（髋关节假体）研究实验的系统：一个操作台加一个仪表盘。这个仓库把它先后几版的代码，和它要接的真实验链 mobo_toy，放在一起存档。每个文件夹都保留了原来的提交历史。

| 文件夹 | 是什么 | 时间 | 原来在哪 |
| --- | --- | --- | --- |
| `1-stem-lab-1112` | 最早一版：地基、操作台、值守、仪表盘和几个示范插件 | 2026-11-12 | `H:\projects\stem-lab` |
| `2-hip-lab-1120` | 第二轮：契约、核心、四类插件和方法包，后来叫停 | 2026-11-14 至 11-20 | `H:\projects\Hip-lab` |
| `3-stem-lab-1.0` | 第三轮：照一页纸从空仓库重搭的 stem-lab 1.0 | 2026-11-20 | `H:\projects\Hip-lab-2` |
| `4-virtual-stem-lab` | 虚拟页面：一个网页，照真实验链装了流程的样子，计算是假的，用来试交互 | 2026-11-21 | `H:\projects\Hip-lab-2\virtual` |
| `5-mobo_toy` | 真实验链：Sawbones 3406 上短柄的 FEA、代理和主动学习选点 | 2026-09-26 起 | `H:\projects\Femoral implant generation\sandbox\mobo_toy` |

## 上传前改了什么

- **地址和用户名换成了占位。** 全部提交历史里，Linux 主机的内网地址、主机名和登录用户名，分别换成了等长的 `<linux-ip>`、`linuxworkstation`、`linux-user`。文件里看到这几个词，原文是真实的地址和用户名。
- **作者邮箱换成了 GitHub 的匿名邮箱。**
- **没提交的改动补成了最后一次提交。** `1-stem-lab-1112` 里有一半插件和架构文档、`5-mobo_toy` 里有几处修改，原仓库当时没有提交，上传时照工作区原样补上。
- **数据没有上传。** 各文件夹 `.gitignore` 排除的东西（实验数据、产出、机器清单、虚拟环境）都不在这里。
- **3 和 4 原来在同一个仓库。** 虚拟页面那次提交的文件放进了 `4-virtual-stem-lab`，其余放在 `3-stem-lab-1.0`。

代码里的命令和路径保持原样，大多只在原来那台机器上能跑。
