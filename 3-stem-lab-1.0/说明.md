# stem-lab 1.0 说明

一个操作台加一个仪表盘。只用 Python 3.12 的标准库，不用装任何包。

## 怎么开

- 双击 `start.bat`：开一个黑窗口，并打开浏览器到 http://127.0.0.1:8765/ 。关掉黑窗口就关了页面；在跑的实验不受影响，再开页面照样看得到。
- 或者在命令行里：`python -m stemlab`。`--port 8766` 换端口；`--data D:\lab-data` 换数据放的地方（默认是这里的 `data\`，不进 git）。数据目录的路径最好只用英文，以后 Abaqus 要在里面跑。
- 只听本机，别的电脑连不上。

## 第一次用

到“登记的东西”页，点“把自带的模板和示例材料登记进来”。自带的东西列在 `examples/catalog.toml` 里，可以随手改；再点一次不会多出东西（登记过、内容没变的不再登记）。

自带五个模板，每类一个，FEA 有两个：

| 模板 | 哪一类 | 是什么 |
| --- | --- | --- |
| 重建示例 | 重建 | 把任何一个文件当作 CT，算出一根“骨”，画各层的皮质厚度 |
| FEA 示例 | FEA | 每个点用一个公式顶替有限元，画每个点的最大应力（带门槛那条线）和柄长对微动 |
| 代理示例 | 代理 | 最小二乘拟合一个多项式，画留出点上的预测值对真值 |
| 优化示例 | 优化 | 在模型的范围里随机撒点，画一批一批搜下来最好的值 |
| Abaqus 检查 | FEA | 一个单元拉伸，照几个应变各跑一次真的 Abaqus，画应力对应变和理论那条线 |

前四个**只是示例，不是科学**：公式是随手写的，只为把六步走通，几秒就跑完。Abaqus 检查是检查用的，不是研究用的：要这台机器装了 Abaqus（启动器的位置是它的一个设置，默认 `D:\SIMULIA\Commands\abq2025.bat`），每跑一次占几秒钟许可证。

然后点“新建实验”。`examples/settings_demo.json` 可以拿来试“从一份外来的设置填表”。

## 页面五处

- **仪表盘**：在跑的（完成数/总数、正在干什么、多久没动静）；哪里停了（最后的进度、日志末尾、退出码；看护进程不在了就显示“中断”）；最近跑完的和判定。每 3 秒刷一次，页面不在前台就不刷，不起任何进程。
- **新建实验**：选哪一类（重建、FEA、代理、优化，加上做法里写的别的类）→ 选做法和要用的东西（下拉框不替你默认选）→ 填设置（每项有默认值和范围；可以从外来的 JSON 或 TOML 填表，认不得的项会列出来）→ 写门槛（可以不写）→ 封存并启动。
- **实验和结果**：列表；点开一个，依次是判定、包画的图、结果表、它用了什么、产出、目录里的文件；可以停下、继续、照这个再开一个。
- **登记的东西**：按类型列出每样东西、从哪来、留底在哪、来历。外来的东西和做法分“第几版”；实验的产出不排版本，写它是哪个实验的。登记表单和“把自带的模板和示例材料登记进来”的按钮也在这里：登记时会抄一份留底。
- **核对**：账本逐行核对（对不上的行都列出来，说清是哪一条），每样登记的东西、每个实验的产出现在和记下时一不一样，还有 data 里有、账本上没有的实验目录和做法留底。账本有对不上的地方时，每一页顶上都会有红字。

## 把一个外来的做法接进来

接一个外来的算法，就是照模板做一个“包”：一份说明（`method.toml`）、几行接头的计算脚本（`run.py`）、一个画图的结果展示（`show.py`）。

1. 照 `methods/template/` 建一个文件夹，里面三样：`method.toml`（名字、哪一类、命令行、要选的东西、设置项、会报的数）、`run.py`（计算）、`show.py`（把算出来的结果画成图）。要用的东西都放在这个文件夹里，不能引用外面的代码。全部约定写在模板的注释里。
2. `run.py` 从实验目录的 `task.json` 读选用的东西、设置和门槛；往 `progress.jsonl` 追加进度；算完调 `show.py` 画图；最后写 `result.json`：报的数、产出、可选的结果表、可选的图（`"figures": [{"title": "…", "path": "out/….svg"}]`，SVG、PNG、JPG 都行）。产出、表、图都要放在实验目录里（比如 `out/` 下面），放在外面的不认。退出码 0 并且有 `result.json` 算跑完。
3. 图怎么画随包：自带的模板用一个几十行、只用标准库的小函数画 SVG，在哪台机器上都出得来；装了 matplotlib 的话也可以存 PNG（模板的 `show.py` 注释里有几行例子）。平台只管把图摆在结果页的判定后面。
4. 在“登记的东西”登记：类型写“做法”，路径指向这个文件夹。`method.toml` 缺了必需的项，登记时就会说第几项缺什么。登记时整个文件夹按指纹抄一份留底，实验跑的是留底那份；以后改了文件夹，再登记一次就是新的一版（内容没变，就不会多出一版）。留底被人动过的话，照原处的文件再登记一次就恢复（核对页上有按钮）。
5. 点“继续”是在同一个目录里再跑一次脚本；上一次的 `result.json` 已被改名成 `result.attempt1.json` 之类留着，要不要接着算由脚本自己看。

## 固定的部分

`stemlab/` 一共 1821 行（含页面的 HTML、CSS、JS）。其中**专门守三件事的约 570 行**，要逐行看的是这几段：

| 文件 | 哪几段 | 约多少行 |
| --- | --- | --- |
| `ledger.py` | 除最后的 `State`、`state`（从账本叠出现状）以外的全部：只往后加、哈希链、头和记下对不上的 `gap`、核对、文件锁 | 225 |
| `fingerprint.py` | 全部 | 46 |
| `things.py` | `label`、`where`、`check`、`_keep`（抄留底）、`register` | 75 |
| `runs.py` | `inside`、`judge`、`seal`、`changed_uses`，`start` 开头的几项核对，`finish`（连同只认实验目录里的图） | 117 |
| `pages.py` | `page` 和 `trouble_html`（每页顶上的红字）、`what`，`gate_text` 和 `same_before`（挪过门槛的提示），`check_page`（核对页） | 105 |

其余是页面的其余部分（`pages.py`、`web.py`）和跑实验（`runs.py` 的其余部分、`__main__.py`），改了不碍三件事。注意：系统的指纹算的是整个 `stemlab/`，改页面上一个字也算换了一个版本，之后的实验页上会照实显示“和封存时不一样”。

测试在 `tests/`（535 行），只测三件事和四类的六步走得通（结果页上有图、一键登记也顺带看了）：`python -m unittest discover -s tests`，约 40 秒。Abaqus 检查不进自动测试（要许可证、慢）。

## 三件事落在哪

**记下来的不被悄悄改**
- `ledger.py`：`append` 只往后加，代码里没有改和删；`_digest` 和 `verify` 是哈希链；每加一条，旁边的 `ledger.head` 记下最后一条的编号和指纹，末尾被砍掉、整个换成旧的、头不见了，一比就知道。`append` 往里加之前先和头比，对不上就先在账本里加一条 `gap` 记下这件事，再照常加（不挡操作），所以痕迹一直留在账本里。`trouble` 让每一页顶上（仪表盘刷新的那一块里也有）在账本现在对不上时说出来。
- `fingerprint.py`：`of` 算指纹，`check` 比对并说出哪个文件变了。
- 登记时把外来的东西（做法也是）抄一份到 `data/store/<指纹>/` 留底，记下指纹（`things.py` 的 `_keep` 和 `register`）；实验用的是留底那份，原处以后怎么变都不影响已登记的版本。实验的产出不抄，由跑完时的目录指纹看着。
- 用的时候核对：`runs.py` 的 `changed_uses`。对不上只剩两种：外来东西的留底被人动过，或者实验的产出跑完以后被人改过。新建时（`web.py` 的 `post_new`）不让启动，并分开说：留底被动过的，给“照原处的文件恢复留底”的按钮（原处也改过的话会成为新的一版）；产出被改过的，给“把它现在的样子登记成一样外来的东西”的按钮。继续时（`runs.py` 的 `start`）也不让启动，说清这两种各该怎么办。
- 实验跑完时给整个实验目录记指纹：`runs.py` 的 `finish`。产出必须在实验目录里（`runs.py` 的 `inside`）。每次启动前，上一次的 `result.json` 改名留着，不会被当成这一次的结果（`runs.py` 的 `start`）。
- 同一个实验最多一个看护进程：它从头到尾握着实验目录外的一把锁（`runs.py` 的 `watch`、`ledger.py` 的 `grab` 和 `held`）。第一次启动时实验目录必须是空的。
- 全量核对：`pages.py` 的 `check_page`。账本里记下的 `gap` 在这里一直列着（“第 64 条记着：在它之前，账本末尾少了 3 条”），不进红字。

**每个结果追得到来历**
- 封存：`runs.py` 的 `seal`。记下类、标题、每样东西和做法的名字、第几版、指纹，全部设置，门槛，`stemlab/` 自己的指纹，照哪个实验开的。每次启动也记下当时 `stemlab/` 的指纹（`start`），和封存时不一样的，实验页上写明。
- 产出登记时带着来历：`runs.py` 的 `finish` 里 `things.register(..., source={"experiment": n})`。
- 页面上摆出来：`pages.py` 的 `experiment` 里“它用了什么”一段，和 `origin`。

**合格的门槛先写定**
- 门槛写在封存里（`runs.py` 的 `seal`），排在结束记录之前；之后没有入口能改或补。
- 判定由核心在收尾时照封存的门槛算：`runs.py` 的 `judge` 和 `finish`。没写门槛就是“未设门槛”，永远不显示合格。
- “先写定”只管到这个实验自己：门槛写在**这个实验**的结果出来之前。如果同一版做法、同样的东西和设置之前已经跑出过结果、门槛却不一样，实验页的判定旁边会写明（`pages.py` 的 `same_before`），只是摆出来，不挡。
- 判定只是记下来、显示出来，不挡任何事：不合格的产出照样能被选，下拉框里带着标记。

## 一页纸末尾没定的四处，现在这样办

每处只占一个地方，好改。第 4 处是用户 2026-11-20 定的；前三处用户还没有表态，是搭的时候先取的办法，不是规矩：
1. （先取的）没有 AI 在旁边也能用：登记东西、登记做法、六步都在页面上；怎么开见上面。
2. （先取的）不同做法的数混不混：不设规矩，只在“它用了什么”和选东西的下拉框里把来历摆出来（`pages.py` 的 `origin`）。
3. （先取的）来历记到哪一层：连系统自己的指纹也记，封存时和每次启动时都记（`runs.py` 的 `seal` 和 `start` 里的 `system`）。
4. （用户定的）门槛：每个实验各写各的，不强制写；写了就封存，由核心判定（`runs.py` 的 `judge`）；挪过要看得出来（`pages.py` 的 `same_before`）。用户没有选“每个做法立一份登记在册的门槛”。

另有一处也是用户 2026-11-20 定的：外来的东西登记时一律抄一份留底（见上面“记下来的不被悄悄改”）。

## 要知道的

- 没有删除。登记错了，就再登记一版或换个名字。`data\` 里的东西别手改，改了“核对”页会认出来，每一页顶上也会有红字。
- 核对的限度：它防的是悄悄改和误改，不防存心伪造。改了某一行、删掉中间几行，每页顶上都有红字，核对页列出是哪几行。砍掉末尾、把账本换成旧的、删掉旁边的头：当时每页顶上有红字；之后照常再用（登记、启动、跑完都会往账本里加），系统会先在账本里记一笔“在它之前，账本末尾少了 N 条”，红字就消失了，核对页上一直列着这一笔。认不出的只剩两种，都要存心：把头也改成和砍过的账本对得上的样子；或者改了以后把后面每一行的指纹全部重算一遍。
- 收尾要花时间：跑完以后，系统要给产出和整个实验目录各算一遍指纹。实测 4 GB 的产出收尾约 6 秒，这段时间仪表盘上一直显示“在跑”，点“继续”会被拦。
- 只有看护进程被杀、做法的进程还活着时（比如在任务管理器里只结束了看护进程），页面会显示“中断”。这时先确认做法的进程（python、abaqus 之类）确实没了，再点“继续”；不然会有两套进程写同一个实验目录。
- 登记外来的东西时会抄一份到 `data/store/` 留底：大文件（比如一整套 CT）登记时要等一会儿（实测 1 GB 的文件约 1.3 秒，那是文件刚写完、还在缓存里；从磁盘冷读会更慢），也多占一份地方；每次启动还要核对一遍留底的指纹，也要等一会儿。之后原处的文件随你动，已登记的版本不受影响，旧实验能照原样重算；要用改过的，再登记一次就是新的一版。
- 留底的文件夹只用指纹命名，但单个文件保留原来的文件名：原文件名带中文的话，`data/` 里的路径就会有中文。以后要给 Abaqus 读的文件，名字请用英文。
- 数据文件夹可以整个挪到别处（再开时用 `--data` 指向新位置）：留底和实验的产出在账本里都按相对数据文件夹的位置记。
- 实验之间不自动接；一个实验的产出只是变成了别的实验可以选的东西。
